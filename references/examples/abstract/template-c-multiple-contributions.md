# Abstract Template C: Multiple Contributions

Use when the paper has several contributions that cannot be collapsed into one core idea.

## Sentence Roles

1. Task or setting.
2. Contrast with prior methods, if needed.
3. Contribution 1 plus advantage.
4. Contribution 2 plus advantage.
5. Contribution 3 plus advantage, if needed.
6. Evidence and value.

## Fill-In Skeleton

`[Task/setting] remains challenging because [main bottleneck]. We introduce [method/framework], which makes three contributions. First, [contribution 1] enables [advantage 1]. Second, [contribution 2] addresses [challenge 2] by [mechanism]. Third, [contribution 3] provides [advantage 3], allowing [capability]. Experiments on [datasets/settings] show [main result], and ablations confirm [causal evidence].`

## Revision Checks

- Each contribution should be paired with an advantage.
- Avoid listing routine modules as contributions.
- If there are more than three contributions, merge or move details to the introduction.
