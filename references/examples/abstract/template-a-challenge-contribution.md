# Abstract Template A: Challenge To Contribution

Use when the paper solves a clear technical bottleneck in an existing task.

## Sentence Roles

1. Task: define the setting and why it matters.
2. Challenge: state the bottleneck and technical reason.
3. Contribution: introduce the method idea.
4. Benefit: explain what the method enables.
5. Evidence: summarize main results.

## Fill-In Skeleton

`[Task] is important for [application/value], but existing methods struggle with [challenge] because [technical reason]. We propose [method], a [method type] that [core mechanism]. By [key design], [method] enables [technical advantage]. Experiments on [datasets/settings] show that [method] [main result], demonstrating [supported claim].`

## Revision Checks

- The challenge should be the exact challenge solved by the method.
- The method sentence should name the core mechanism without full implementation detail.
- The result sentence should not claim more than the experiments show.
