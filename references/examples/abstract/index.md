# Abstract Examples Index

Use this index to choose an abstract template.

## Template A: Challenge To Contribution

Read `template-a-challenge-contribution.md` when the abstract needs a direct task -> challenge -> method -> result shape.

Best for:

- known task,
- clear technical bottleneck,
- one main method contribution.

## Template B: Challenge To Insight To Contribution

Read `template-b-challenge-insight-contribution.md` when the paper's novelty is an insight, observation, or principle.

Best for:

- observation-driven methods,
- papers where "why it works" is more important than module listing,
- abstract currently feels like a pile of components.

## Template C: Multiple Contributions

Read `template-c-multiple-contributions.md` when the paper has two or three real contributions that must be named separately.

Best for:

- new framework + new module + new benchmark,
- method plus dataset/analysis,
- multiple modules with distinct advantages.
