# Method Common Issues

Use this to diagnose a weak Method section.

## Issue: Figure-Only Method

The figure shows the pipeline, but the text does not explain the steps.

Repair: write an input -> operation -> output paragraph for each module.

## Issue: Motivation Missing

A module appears without a reason.

Repair: add a challenge sentence before the design paragraph.

## Issue: Advantage Not Testable

The method claims to be robust, efficient, or accurate without an experiment.

Repair: add an ablation, efficiency table, robustness test, or weaken the claim.

## Issue: Inconsistent Notation

The same object has different names or symbols across text, figure, and equations.

Repair: choose one notation and define it near first use.

## Issue: Patch-Like Story

The method reads as a sequence of fixes to a weak baseline.

Repair: reorganize around the core principle or pipeline goal.
