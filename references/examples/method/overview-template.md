# Method Overview Template

Use for the first subsection or first paragraph of Method.

## Required Content

1. Task setting.
2. Inputs and outputs.
3. Core idea.
4. Pipeline modules.
5. Pointer to the figure, if available.
6. Subsection map.

## Fill-In Skeleton

`Given [input], our goal is to [output/task] under [setting]. As illustrated in Fig. X, [method] follows [core idea]. The pipeline contains three components: [module A], [module B], and [module C]. [Module A] [role], [Module B] [role], and [Module C] [role]. Sections X.1-X.3 describe these components in order.`

## Checks

- Can a reviewer draw the pipeline from this paragraph?
- Are module names paired with functions?
- Does the overview avoid low-level implementation detail?
