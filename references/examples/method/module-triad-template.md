# Method Module Triad Template

Use for a module subsection.

## Subsection Shape

1. Motivation paragraph.
2. Design paragraph.
3. Advantage paragraph.

## Motivation Skeleton

`A key challenge in [stage/problem] is [challenge]. Existing [approach/module] often [failure mode] because [technical reason]. We introduce [module] to [function].`

## Design Skeleton

`Given [input], [module] first [step 1]. It then [step 2] using [representation/network/objective]. Finally, it outputs [output], which is used to [downstream role].`

## Advantage Skeleton

`This design provides [advantage]. Because [mechanism], it can [behavior] under [condition]. This advantage is evaluated in [experiment/ablation reference].`

## Checks

- Motivation ties to a real challenge.
- Design is executable.
- Advantage is testable.
