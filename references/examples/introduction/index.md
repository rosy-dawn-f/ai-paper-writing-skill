# Introduction Examples Index

Use this index to choose detailed introduction patterns.

## Opening Patterns

Read `opening-patterns.md` when the first paragraph is weak, too broad, or unclear.

Patterns:

- task first, then applications,
- applications first,
- general task to specific setting,
- open with challenge.

## Challenge Patterns

Read `challenge-patterns.md` when the introduction fails to motivate the technical gap.

Patterns:

- existing task with method chain,
- existing task with historical insight,
- novel task or setting with challenge decomposition.

## Pipeline Patterns

Read `pipeline-patterns.md` when the method preview feels arbitrary or incremental.

Patterns:

- one contribution with multiple advantages,
- two contributions,
- gap-driven funnel with optional branches,
- new module on existing pipeline,
- observation-driven contribution.

## Not Recommended Patterns

Read `not-recommended-patterns.md` when the writing hides concrete design behind abstract novelty language or makes the method look like a patch.
