# Paragraph Flow And Reverse Outlining

Use this reference when the user asks whether a paragraph flows, whether writing is clear, or whether a section is coherent.

## Core Test

Read as an external reviewer:

- Does the paragraph have one explicit message?
- Does the first sentence state that message or the paragraph's role?
- Are key nouns, terms, methods, datasets, and symbols understandable without hidden context?
- Does each sentence connect to the previous sentence by cause, contrast, consequence, refinement, or example?
- Does the paragraph support the section thesis?

## Reverse Outline

For a section:

1. Write the section's main claim.
2. Write each paragraph's topic sentence.
3. Write the evidence or explanation under each paragraph.
4. Check whether every topic sentence supports the section claim.
5. Check whether every evidence sentence supports its topic sentence.
6. Remove, split, merge, or reorder paragraphs that do not map cleanly.

## Common Flow Breaks

- A paragraph tries to do two jobs.
- The first sentence is background rather than the paragraph message.
- A new term appears before its function is clear.
- Pronouns refer to several possible nouns.
- A sentence jumps from problem to method without a bridge.
- A contrast word appears when the relationship is not contrast.
- Evidence appears before readers know what question it answers.

## Repair Moves

- Add or replace the topic sentence.
- Split mixed paragraphs by role.
- Move definition close to first mention.
- Repeat the noun instead of using an ambiguous pronoun.
- Add a short bridge phrase naming the relationship.
- Move supporting evidence after the claim it supports.
- Use temporary section headers while revising, then remove unnecessary ones.

## Output Pattern

Return:

1. Flow diagnosis in one or two sentences.
2. Reverse outline.
3. Specific flow breaks.
4. Revised paragraph or paragraph order.
